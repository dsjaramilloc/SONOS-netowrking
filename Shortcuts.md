# **Win shortcuts Tips & tricks.md**

 

* Ctrl + C Copy

* Ctrl + V Paste

* Ctrl + Z Erase

* Ctrl + F Search within the page I have open

* Ctrl + E Open the search bar

* Ctrl + A Select all

 

* Win + Shift + S  Take a screenshot

* Delete = Erase the text after your cursor

* Home Guides your cursor on the beginning of the text

* End Helps you to get to the bottom of a page or document you are navigating thru

* Tab Moves forward
 

* Shift + Tab  Moves back

* Shift + Home >> Selects all the text where your cursor is

* Shift + End  >> Selects to the end to the text

* Ctrl + Shift + right-arrow Selects the text starting from the text your cursor is to the right

* Ctrl + Shift + Left-arrow Selects the text starting from the text your cursor is to the left

* Shift + Home >>Selects the text where your cursor is

* Shift + End  >> Selects to the end to the text

* Ctrl + Shift + N --> Open a inprivate browser page

* F2  --> Cambiar nombre a archivo

* Alt + Tab --> Helps you to navigate thru to the differents apps you have open

* Alt + F4 --> Helps you to close the app you have open
